# 浏览器云端个人桌面 V0.11 Wormhole 施工计划

状态：施工中（自动验证通过，等待真实客户端验收）

日期：2026-07-30

## 阶段 1：Runtime 与控制面

状态：已完成。

- 实现进程内 WormholeRuntime；
- 10 位安全随机密码、常量时间认证、轮换和关闭；
- 活动请求 abort、锁清理和失败限速；
- internal 控制 API；
- 注册 `system.wormhole` 与基础界面；
- 覆盖重启默认关闭、幂等开关、旧凭据撤销和 no-store。

出口：用户可以安全开启、复制凭据、轮换和关闭，但尚不提供文件协议。

## 阶段 2：只读 WebDAV

状态：已完成自动测试，等待 rclone / Explorer / Finder 实测。

- 严格 path codec 与 EntryIndex 路径解析；
- OPTIONS；
- PROPFIND Depth 0/1 和属性投影；
- HEAD；
- GET 与单 Range；
- Basic challenge、跨站拒绝、XML 上限和响应转义；
- 背压、连接中止和内容并发限制。

出口：rclone、Windows Explorer 和 Finder 能列目录并流式读取文件。

## 阶段 3：写入与目录操作

状态：主体已完成；CAS 冲突采用明确失败，不在第一版隐藏重试。

- PUT 新建和替换；
- X-OC-Mtime；
- MKCOL；
- DELETE；
- MOVE 与 Destination/Overwrite；
- COPY 与 FID 复用；
- atomic overwrite batch；
- If-Match、If-None-Match 与 CAS 重试；
- 大小写冲突规则。

出口：常见文件交换和 rclone copy/sync 所需写操作闭环。

## 阶段 4：锁与客户端兼容

状态：最小 LOCK/UNLOCK、lock-null、文件 mtime PROPPATCH 已完成，等待真实客户端校正。

- LOCK/UNLOCK、刷新、lock-null 和 10 分钟上限；
- PROPPATCH 最小 mtime 支持；

## 实施原则

- 先控制面和只读，再开放写入；
- 每增加一个 WebDAV 方法先完成协议测试；
- 不以“客户端似乎能用”替代 PVLog 原子性和失败语义；
- 不因兼容单个客户端引入实时同步、多用户或第二套元数据系统；
- 不修改第三方开发者协议。
