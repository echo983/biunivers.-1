## 合并门槛

- Resource Session 是推荐接口，Host API v1 保持原语义；
- Handler 不产生同类型文件枚举权；
- session ID 不进入 URL；
- Range 只读取必要 Chunk，且完整校验每个已读 Chunk；
- 多次 Range 始终绑定同一不可变内容快照；
- read 会话不能 PUT；
- 保存冲突不覆盖当前版本；
- 应用状态变化能撤销会话；
- 过期会话不能续租复活；
- 旧 Notepad 和 Open Resource v1 无回归；
- 不修改 PVLog、RefStore、S3 权限或冻结协议原文。
