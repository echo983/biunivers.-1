# 浏览器云端个人桌面 V0.3 施工与验收归档

状态：施工与验收完成，归档版本 `v0.3.0`

归档日期：2026-07-29

版本主题：Biunivers File Service V0.1 与 Host API v1

## 交付范围

V0.3 在 V0.2 第三方静态应用生态上增加可选的单用户文件能力：

- S3 兼容后端中的 create-only 不可变协议对象；
- XXH3-128 写前 FID 与读后校验；
- 64 MiB 固定分片、Manifest 和流式 HTTP 传输；
- Docker 持久卷中的 SQLite RefStore 与 CAS 发布；
- 每应用独立 Origin、窗口实例、文件句柄和一次性传输 capability；
- 宿主文件选择器、保存对话框和 `biunivers.host-api/1`；
- 在线一致性 RefStore 备份、独立恢复校验和只读 GC 报告。

本版本不包含多用户、多副本写入、应用间资源交换或 GC 删除。

## 验收摘要

- 新建、另存为、覆盖保存、重新打开和容器重启恢复通过；
- 旧句柄写入冲突不会覆盖新版本；
- 64 MiB + 1 字节文件通过两个 Chunk 和一个 Manifest 完整读回；
- 在线备份恢复到全新 Docker 卷后，revision、根 Entry 和文件内容一致；
- 恢复扫描重新读取所有文件并通过 XXH3-128 校验；
- 真实 R2 GC 报告中 16 个协议对象全部可达、候选为 0；
- GC 响应为 `deletionAllowed: false`，实现不存在删除路由。

完整证据见 [File Service V0.1 首轮验收](<acceptance/File Service V0.1 首轮验收.md>)。
