## 提交建议

每阶段独立提交：

1. `feat: validate open resource handlers`
2. `feat: resolve resource handlers`
3. `feat: issue resource launch contexts`
4. `feat: deliver resource launches to apps`
5. `feat: open files from file manager`
6. 记事本仓库独立提交
7. `docs: archive open resource v0.5`

## 合并门槛

- Static App、Manifest 和 Host API v1 原文未被修改；
- 传统应用不能伪造 managed Handler；
- 默认关联不授予文件权限；
- launchId、handle、FID、S3 Key 和 Ref 不进入 URL 或持久化；
- 跨应用和跨窗口 claim 被拒绝；
- 现有单实例窗口行为没有回归；
- 文件打开失败不改变 PVLog 或 Ref；
- 文件保存继续使用既有版本冲突保护；
- 主仓库和记事本均完成自动化与真实环境验收；
- 文档、Schema、实现和开发者包一致。
