# 浏览器云端个人桌面 V0.2 施工计划

状态：待施工

目标：交付第三方静态应用安装、托管和管理闭环

## 1. 施工原则

- 每个阶段都产生可验证结果；
- 优先打通纵向链路，再补充生命周期；
- 服务端规则必须有自动化测试；
- 不执行第三方仓库代码；
- 不把 future protocol 能力混入 V0.2；
- 发现协议问题时同步修改协议、Schema、模板和实现；
- 未通过阶段出口条件，不提前宣称功能完成。

- 卸载后服务重启不会恢复应用。

## 11. 风险和控制

| 风险 | 控制 |
|---|---|
| GitHub API 限额或网络波动 | 可选服务端 token、明确错误、本地 fixture 测试 |
| archive 路径攻击 | 限定 host、流式上限、路径规范化、拒绝链接 |
| 安装半成品进入桌面 | staging、最后写 APP 记录 |
| 更新破坏当前版本 | 新目录安装、成功后原子切换 |
| 管理 token 被第三方读取 | 双 origin、token 仅 Desktop Origin 内存 |
| 配置被误当 secret | 协议限制、UI 警告、无 secret 类型 |
| 协议与代码漂移 | Schema/模板/实现共享 fixture 和一致性测试 |
| 服务端扩大部署复杂度 | 单进程、JSON 状态、单容器和单数据卷 |
| 范围扩张到插件平台 | 坚守非目标，资源交换单独立项 |

- 完成的阶段在本文档中标记并留下验证记录；
- 合并前工作区干净且远端 CI 通过。
