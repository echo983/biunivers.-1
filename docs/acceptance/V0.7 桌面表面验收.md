## 4. 语义与安全结论

- DesktopItem 保存长期稳定 handle，不保存短期 capability；
- app、file 和 directory 只由宿主内建 Resolver 解析；
- 添加或移除桌面入口不移动、复制、删除文件，也不安装或卸载应用；
- 从任务栏移除只取消固定，不关闭正在运行的窗口；
- 文件打开仍通过既有 Handler、Pending Launch 和 capability 流程；
- 失效引用保留在桌面，生命周期变化不会造成静默数据丢失；
- 多项目布局更新全成或全败，并由 revision/CAS 防止跨标签覆盖。

逻辑像素坐标，并限制桌面交互边界；更复杂的跨视口投影应在后续版本独立设计。
