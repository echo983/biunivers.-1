## v0.16.1 首次安装修复

首次 VPS 安装暴露出 Runtime 从 `process.cwd()` 定位 PVLog WASM 的错误；安装命令从 `/root`
执行时，genesis 在访问 S3 前以 `MODULE_NOT_FOUND` 失败。v0.16.1 改为相对模块文件定位，并在
Debian Runtime 打包阶段从非应用工作目录真实加载 WASM。安装器还会延迟切换 `current`，直到
S3/genesis 验证成功，并允许没有 RefStore、服务未运行的失败安装安全续装到修复版本。
