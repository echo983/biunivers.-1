# V0.15 BWA 配置与 Workspace 内容补充里程碑

状态：已归档  
版本：`v0.15.0`  
日期：2026-08-06

## 交付内容

- BWA Application 默认普通变量与默认 secret；
- Instance 差异覆盖和启动时最终环境合并；
- RefStore Schema v6 与旧 v1–v5 原子迁移；
- 文件管理器将 main 文件或递归目录添加到已有 Workspace；
- 内容 FID 复用、新 Entry ID、同名自动改名；
- main Ref、Workspace Ref、写租约和异常 Run 的原子发布守卫；
- Runtime 尚未接管 Run 时的幂等失败清理。

## 兼容与边界

- Workspace Application Protocol 仍为 v1，第三方镜像无需适配新协议；
- 既有 Instance 环境继续作为覆盖项，升级后行为不变；
- 已运行 Run 不热更新环境；
- BWA 不获得 main 浏览、主动选择或同步能力；
- 不实现配置 Profile、跨 Universe 移动或实时同步。

## 质量门禁

- 全量 Vitest：444 通过，1 跳过；
- TypeScript 客户端与服务端构建通过；
- 变更源码 ESLint 与 `git diff --check` 通过；
- Application 默认继承、Instance 模型覆盖、单文件、递归目录和同名导入均通过真实界面验收；
- README、现行 runbook、第三方开发包、文档索引和关于界面已同步。

## 结论

V0.15 解决了 BWA 多 Instance 重复填写公共配置和 Workspace 创建后难以继续补充资料的两个
高频缺口，同时保持第三方应用不能遍历 main、Workspace 固定 Head 和不可变对象复用边界。
当前 `main` 达到发布 `v0.15.0` 的条件。
