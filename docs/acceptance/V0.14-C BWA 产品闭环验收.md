## 3. 实测修正

1. Runtime 状态根改用短路径，避免 Run gateway Unix socket 超长；旧保留 Upper 在 daemon
   启动前受控迁移，冲突时失败关闭。
2. BWA iframe 属于跨站子域；`SameSite=Strict` 会被 Chrome 拒绝。宿主会话改为
   `SameSite=None; Secure; Partitioned`，既允许 iframe，又绑定当前顶层 Biunivers 站点。
3. 已存在的 BWA 窗口重新打开时必须刷新一次性 bootstrap URL，不能只把旧窗口置前。
4. Workspace Fork 的新 Ref 必须继承源 HEAD 对应的 revision；Ref ID 独立并不意味着
   revision 可以归零。
5. 诊断镜像未快速处理 `SIGTERM` 时，停止会用满 Docker 的 10 秒宽限期；这是安全上限，
   不是提交性能问题。正式 BWA 应让 PID 1 正确处理终止信号。
