15. 面包屑位于工具栏下方，根目录与层级显示为 `/ › 目录`，导航正常。

## 4. 存储与安全结论

- 新建和复制接口只接受 Desktop Origin 与 `system.files` 实例；
- 每次成功操作仅发布一个新 Entry 和一个新 revision；
- 大文件复制不读取、下载、重分片或重新上传 Chunk/Manifest；
- 复制不泄露 FID、对象 Key、Ref 或 S3 凭据；
- stale revision、重名和目录复制均在发布前被拒绝；
- 文件夹递归复制继续保留到支持多 Entry 原子事务的后续版本。

## 5. 结论

V0.6 在不改变 PVLog、Host API 或第三方协议的前提下，补齐了新建普通文件、当前目录文件复制
和可靠加载反馈。自动化与真实环境均未发现阻止合并的问题。
