Nassau App Manifest v1

Identification

Protocol name: Nassau App Manifest
Format identifier: nassau.appmanifest
File extension: .appmanifest
Media type: application/vnd.nassau.appmanifest+json

Minimal Manifest

{
  "format": "nassau.appmanifest",
  "formatVersion": 1,
  "hostApi": "nassau.host/1",

  "entry": "/app/main.js",

  "requires": [
    "web-workers",
    "webcodecs"
  ],

  "files": [
    {
      "path": "/app/main.js",
      "sha256": "1111111111111111111111111111111111111111111111111111111111111111",
      "mediaType": "text/javascript"
    },
    {
      "path": "/app/style.css",
      "sha256": "2222222222222222222222222222222222222222222222222222222222222222",
      "mediaType": "text/css"
    },
    {
      "path": "/wasm/player.wasm",
      "sha256": "3333333333333333333333333333333333333333333333333333333333333333",
      "mediaType": "application/wasm"
    }
  ],

  "capabilities": {
    "network": [
      "https://media.example"
    ],
    "features": [
      "audio-output",
      "fullscreen",
      "private-storage"
    ]
  }
}

Fields

"format"

Must equal:

"format": "nassau.appmanifest"

"formatVersion"

Manifest format version.

"formatVersion": 1

Unknown versions must be rejected.

"hostApi"

Required Nassau host interface version.

"hostApi": "nassau.host/1"

The host API version is independent of the manifest format version.

"entry"

Absolute virtual path of the JavaScript ES module entry point.

"entry": "/app/main.js"

The entry file must:

- exist in "files";
- use the "text/javascript" media type;
- export:

export async function start(host) {
}

"requires"

Runtime features required before the application can start.

"requires": [
  "web-workers",
  "webcodecs"
]

Defined v1 values:

web-workers
wasm-simd
wasm-threads
webgpu
webcodecs
web-audio

An unsupported or unknown required feature makes the application incompatible with the current host.

"files"

The complete immutable application file set.

Each item contains:

{
  "path": "/wasm/player.wasm",
  "sha256": "3333333333333333333333333333333333333333333333333333333333333333",
  "mediaType": "application/wasm"
}

"path"

Application-internal virtual path.

Requirements:

- starts with "/";
- uses "/" as the separator;
- is case-sensitive;
- contains no empty, "." or ".." segments;
- is unique within the manifest.

"sha256"

SHA-256 digest of the original file bytes.

Format:

64 lowercase hexadecimal characters

Digests must be calculated from real files and must not be guessed or generated by an AI model.

"mediaType"

MIME media type of the file.

Examples:

text/javascript
text/css
application/wasm
application/json
image/png
font/woff2

"capabilities"

Maximum external capabilities available to the application.

{
  "network": [],
  "features": []
}

Both arrays are required.

"network"

Exact network origins the application may access.

"network": [
  "https://media.example",
  "https://api.example:8443"
]

Wildcards are not allowed in v1.

Invalid examples:

*
https://*
*.example.com

Host downloads of manifests and application objects are not application network access.

"features"

Defined v1 capability values:

audio-output
fullscreen
open-file
private-storage
camera
microphone
clipboard-read
clipboard-write
notifications

A declared capability is an upper bound. Browser permission or user approval may still be required.

Undeclared capabilities must not be exposed to the application.

Virtual Path Resolution

All application resources exist in one virtual file tree.

Example:

/app/main.js
/app/style.css
/wasm/player.wasm

Relative paths are resolved against the importing file.

../wasm/player.wasm

When referenced from:

/app/main.js

resolves to:

/wasm/player.wasm

The resolved path must exist in "files".

Executable JavaScript, WebAssembly, Worker or CSS resources not listed in "files" must not be loaded or executed.

Network content is data by default, not executable application code.

Manifest Identity

The manifest digest is calculated as follows:

1. Reject duplicate JSON properties.
2. Reject unknown fields.
3. Sort "files" by "path".
4. Sort "requires" lexicographically.
5. Sort "capabilities.network" lexicographically.
6. Sort "capabilities.features" lexicographically.
7. Canonicalize the JSON using RFC 8785 JCS.
8. Encode the canonical JSON as UTF-8.
9. Calculate SHA-256.

Digest format:

sha256:<64 lowercase hexadecimal characters>

The manifest digest is the immutable identity of one executable application version.

External Release Record

The following information is outside "nassau.appmanifest":

- persistent application ID;
- release version;
- display name;
- description;
- icon;
- publisher identity;
- signature;
- release channel;
- download locations;
- publication time.

Example release record:

{
  "appId": "org.example.player",
  "releaseVersion": "2.1.0",
  "channel": "stable",
  "manifest": "sha256:aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
  "publisher": "example-inc",
  "signature": "..."
}

Responsibility separation:

nassau.appmanifest
Defines the executable object.

Release record
Defines its publisher, name and release status.

Distribution hub
Determines trust and execution policy.

Object servers
Provide content without defining its identity.

Required Host Behavior

A Nassau v1 host must:

1. verify the manifest digest;
2. verify every file digest before use;
3. verify "hostApi" compatibility;
4. verify all required runtime features;
5. construct the virtual file tree;
6. enforce declared capabilities;
7. load the entry module;
8. call "start(host)";
9. reject undeclared executable resources;
10. isolate application execution and persistent state.

Definition

«"nassau.appmanifest" is a content-addressed executable manifest for browser-hosted applications. It defines the host API version, entry point, required runtime features, immutable file set and capability boundary. Its digest identifies one exact executable application version. Publisher identity, signatures, release channels, names and download locations are handled by the external distribution system.»
