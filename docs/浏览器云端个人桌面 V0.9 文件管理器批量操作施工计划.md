# 浏览器云端个人桌面 V0.9 文件管理器批量操作施工计划

状态：已完成并归档（`v0.9.0`）

日期：2026-07-29

## 阶段 1：多选基础

- Set + anchor 状态；
- 普通、Ctrl/Command、Shift、组合选择；
- 多选计数和单项动作禁用；
- 选择行为单元测试。

## 阶段 2：批量 PVLog 事务

- WASM 批量操作编码 ABI；
- FileSystemTransactions 批量发布入口；
- 服务端选择规范化、冲突与环检测；
- 批量移动和删除 API；
- 原子性、revision 与失败不发布测试。

## 阶段 3：批量复制

- 递归展开目录；
- 新 Entry ID 映射；
- 复用文件内容 FID；
- 项目数量上限；
- 批量复制 API 与测试。

## 阶段 4：UI 与验收

- 批量目标目录对话框；
- 工具栏批量移动、复制、删除；
- 桌面失效联动；
- lint、单元测试、构建、容器和真实浏览器验收；
- 文档归档与里程碑合并。

## 完工记录

- Ctrl/Command 切换选择、Shift 连续区间和组合追加选择均已实现；
- Shift 点击已阻止浏览器原生文字选择；
- 批量移动、复制和删除均以一个 PVLog Segment、一次 Ref CAS 和一个 revision 原子提交；
- 目录复制递归生成新 Entry ID，文件内容直接复用原 FID，不发生 S3 内容搬运；
- 祖先与后代同时入选时只处理最上层祖先；
- 冲突、环路、根目录、数量上限和过期 revision 均由服务端校验；
- 自动测试、lint、生产构建、Docker/R2 和真实浏览器验收全部通过。

V0.9 不引入第三方文件系统遍历能力，也不包含标签系统。批量接口只服务于编译期白名单中的
内建文件管理器。
