# 浏览器云端个人桌面 V0.9 文件管理器批量操作需求方案

状态：已实现并通过 V0.9 验收

日期：2026-07-29

## 目标

文件管理器支持标准的 Ctrl/Command 与 Shift 多选，并以同一选择集合完成批量移动、复制和
删除。批量操作必须全成或全败，不能产生用户难以恢复的半完成状态。

## 选择行为

- 普通点击：只选当前项目并设置选择锚点；
- Ctrl/Command + 点击：切换当前项目，当前项目成为新锚点；
- Shift + 点击：按当前列表顺序选择锚点到当前项目的连续区间；
- Ctrl/Command + Shift + 点击：把连续区间加入当前选择；
- 点击表格空白：清空选择；
- 进入或刷新目录：清空选择与锚点；
- 双击项目：先按普通点击语义选择，再打开文件或进入目录；
- 已选择多项时，重命名、下载、打开方式和添加到桌面等单项动作禁用；
- 工具栏显示“已选择 N 项”。

## 批量操作

移动：

- 保留原名称和 Entry ID；
- 选择中同时包含祖先目录和其后代时，只提交最上层祖先；
- 禁止移动根目录；
- 禁止目录移入自身或后代；
- 任一目标名称冲突则整批拒绝。

复制：

- 文件复用原内容 FID，不重新 GET/PUT 内容；
- 文件和目录均生成新 Entry ID；
- 目录递归复制完整 Entry 结构；
- 同时选择祖先与后代时只复制最上层祖先；
- 任一目标名称冲突则整批拒绝；
- 第一版不提供覆盖、合并、跳过和自动改名。

删除：

- 文件直接移除；
- 目录递归移除；
- 同时选择祖先与后代时只提交最上层祖先；
- 删除成功后桌面对应项目立即标记不可用。

## 非目标

- 跨目录搜索结果多选；
- 拖拽批量移动；
- 剪贴板复制粘贴；
- 冲突逐项处理；
- 撤销；
- 第三方应用文件系统遍历；
- 标签实现。

标签将在后续复用本版本的选择集合，但不与批量文件事务捆绑。
