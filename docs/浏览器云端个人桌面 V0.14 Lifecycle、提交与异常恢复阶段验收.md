# 浏览器云端个人桌面 V0.14 Lifecycle、提交与异常恢复阶段验收

日期：2026-07-31  
分支：`feature/workspace-application-manager-v0.14`  
结论：**V0.14-B 通过，可以进入 V0.14-C 局部设计。**

## 1. 验收范围

本阶段只验收 BWA 的运行状态与 Workspace 数据闭环：

- 固定 digest 动态 OCI Run；
- start、stop、exit、保存重启和受控关机；
- COW 提交、异常 Upper、daemon 中断恢复；
- Application 更新门与单次回退。

私有网络、HTTP 反向代理、iframe 协议和产品管理界面属于 V0.14-C，不作为本阶段缺口。

## 3. 评审中修正的问题

1. 宿主不能覆盖镜像自身 `WORKDIR`，Workspace 只是 `/workspace` 挂载点。
2. 提交失败时，本地 manifest 与控制 Run 必须同时进入 FAILED，否则异常 Upper 无法处置。
3. 非受控中断不能自动提交已停止但尚未发布的 Upper。
4. 受控关机保持 `desiredState=RUNNING`；它表示用户意图，不等于容器仍在运行。
5. 回退必须恢复旧 digest 对应的 OCI 元数据，不能只交换 digest。

## 4. 保留的边界

- Supervisor 只提供低频单次巡检原语；定时器生命周期在 Manager 接线时加入。
- 第一版不恢复同一容器或同一 Upper 继续运行。
- 第一版不自动合并异常 Upper 与已前进的 Workspace Ref。
- 第一版不引入通用调度器、Compose 模型或复杂自动重启策略。

这些边界不破坏数据闭环，并避免 V0.14-B 演化成容器编排系统。
